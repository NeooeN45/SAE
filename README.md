# Loc'Home — site de démonstration (SAE Piloter)

Site vitrine d'une **entreprise fictive**, réalisé pour l'oral de la SAE Piloter
(groupe 1, BUT Carrières Juridiques, semestre 1, IUT de Saint-Malo, 2026-2027).

Loc'Home, « la bibliothèque des objets », propose la location d'appareils
électroménagers. Aucune location ni aucun paiement réel n'est proposé : le
formulaire de contact est une démonstration et n'envoie rien.

## Contenu

Tout le site tient dans `index.html` (images incluses) :

- Accueil
- Catalogue avec recherche, filtres et simulateur d'emprunt
- Abonnements (tarif standard et tarif étudiant)
- Boutique : visite 3D et maquette de la boutique dans sa galerie
- Équipe
- Contact

## Mise en ligne

Le site est statique : il suffit d'activer GitHub Pages sur la branche `main`
(dossier racine), ou d'ouvrir `index.html` dans un navigateur.
